## Series format

- 1080×1920 · 60 fps · 90–100 s · Bangla captions (no VO) · original BGM + SFX
- Look: ink black + cream type + **lime** accent; red only for the "bad news" beat; gold for ratings
- Persistent HUD: story-style chapter bar, `BAUBC · CASE STUDIES` chip, chapter name
- Visual style may change per episode (EP01 neon UI, EP02 flat explainer illustration); palette, HUD and captions stay
- Always ends on the CASE STUDIES logo animation → [`/logo-animations/case-studies`](../logo-animations/case-studies/)
